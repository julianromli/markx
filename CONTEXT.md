# Mark

A spatial workspace for collecting and arranging bookmarks, folders, notes, and images on a board.

## Language

**Bookmark**:
A saved web link placed on a board, with a title and optional preview metadata.
_Avoid_: Card (the card is only the visual), link item

**Bookmark URL**:
The canonical full address of a Bookmark (`https://…`), including path, query, and hash when present.
_Avoid_: Href, link, "full url address"
